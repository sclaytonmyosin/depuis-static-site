# Depuis - Static Site

This repository contains a static export of the [Depuis](https://depuis.org) WordPress website, generated using the Simply Static plugin.

## Purpose

This static export is being used to migrate the site off WordPress hosting and onto Replit.

## Contents

The static export includes the site's HTML, CSS, JavaScript, and media assets, allowing the site to be served without a PHP/MySQL backend.

## Notes

- Dynamic WordPress features (forms, comments, logins, etc.) are not included in this static export and will need separate handling if required.
- Generated from depuis.org on 2026-07-29.
